# Práctica 1 - Maquetación Web con HTML5 y CSS

## Descripción del proyecto
En este proyecto se realiza la maquetación de dos secciones de una página web de servicios de hosting, aplicando buenas prácticas de estructura semántica con HTML5 y estilos con CSS.

## Plan de Trabajo

### Objetivo
Construir la estructura de dos secciones completas de una página web: sección de planes de precios y sección de soporte y herramientas.

### Estimación de tiempos
| # | Actividad | Tiempo estimado |
|---|---|---|
| 1 | Creación de archivos y estructura del proyecto | 10 min |
| 2 | Maquetación HTML - Sección de planes | 40 min |
| 3 | Maquetación HTML - Sección de soporte y herramientas | 35 min |
| 4 | Redacción del README.md | 15 min |
| 5 | Aplicación de estilos con CSS | 45 min |
| 6 | Validación y pruebas | 15 min |
| **Total** | | **~2 h 40 min** |

### Tecnologías utilizadas
- HTML5 — Estructura semántica
- CSS3 — Estilos visuales
- Git + GitHub — Control de versiones
